# 📊 Retail Sales Performance Dashboard

An interactive Power BI dashboard designed to analyze retail sales, profitability, product categories, and business performance.

## 📸 Dashboard Preview

![Retail Sales Dashboard](Screenshot%202026-10-12%20234350.png)

## 🎯 Project Objective

The objective of this project is to transform retail sales data into meaningful insights that can help businesses understand sales performance, evaluate profitability, and make data-driven decisions.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **DAX** — Measures, calculations, and dynamic metrics
- **Power Query** — Data transformation and preparation
- **Excel** — Source data

## 📈 Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Quantity
- Profit Margin

## 📊 Dashboard Features

- Interactive sales and profit analysis
- Regional performance comparison
- Category and sub-category analysis
- Shipping mode and customer segment analysis
- Dynamic metric selection
- Interactive filters and slicers
- Profitability analysis
- Conditional formatting
- Key Influencers analysis
- Top and bottom sub-category analysis

## 💡 Business Questions Explored

- Which regions contribute to sales performance?
- Which categories and sub-categories generate sales and profit?
- How does profitability vary across business segments?
- Which shipping modes are associated with different sales patterns?
- Which sub-categories have higher or lower profitability?

## 🔍 Key Insights

The dashboard helps explore patterns in sales, profit, quantity, and profitability across regions, categories, customer segments, and shipping modes.

Specific business recommendations should be based on the results observed in the dashboard.
