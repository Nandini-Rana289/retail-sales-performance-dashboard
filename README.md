# 📊 Retail Sales Performance Dashboard

An interactive Power BI dashboard for analyzing retail sales, profitability, product categories, and regional performance.

## 📸 Dashboard Preview

![Retail Sales Dashboard](Screenshot%202026-10-12%20234350.png)

## 🎯 Project Objective

The objective of this project is to analyze retail sales data and transform it into meaningful business insights that support data-driven decision-making.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Microsoft Excel

## 📈 Key Performance Indicators

- Total Sales
- Total Profit
- Total Quantity
- Profit Margin

## 📊 Dashboard Features

- Regional sales comparison
- Category and sub-category analysis
- Sales and profit analysis
- Shipping mode analysis
- Interactive slicers and filters
- Dynamic metric selection
- Profitability analysis
- Conditional formatting
- Key Influencers analysis
- Top and bottom sub-category analysis

## 💡 Business Questions Explored

- Which region generates the highest sales?
- Which category generates the highest profit?
- Which sub-categories contribute most to sales?
- Which sub-categories are generating losses?
- How do sales and profitability vary across regions and categories?

## 🔍 Key Business Insights

### 1. Regional Performance
The West region recorded the highest sales, at approximately $0.73M.

**Recommendation:** Analyze successful products and customer segments in this region to identify opportunities for continued growth.

### 2. Category Profitability
Technology generated the highest profit among the three major categories.

**Recommendation:** Investigate the products driving Technology's profitability and evaluate opportunities to strengthen performance.

### 3. Sub-Category Sales
Phones recorded the highest sales among the sub-categories shown in the dashboard.

**Recommendation:** Monitor demand and stock availability to support sales performance.

### 4. Loss-Making Sub-Categories
Bookcases, Supplies, and Tables recorded negative profit.

**Recommendation:** Review product costs, discounts, and pricing to identify potential improvements.

*These insights are based on the dashboard results. Recommendations are suggested actions and require further analysis before implementation.*
